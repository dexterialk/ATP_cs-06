# Team

## What it shows
Team CS-06 in a plain grid: photo, name, role.

## Ball state
`off-screen`: the ball leaves the viewport.

## Content source
The `members` list in `team.njk`. **Names, roles and photos are placeholders.**

## What to edit
- Edit `members` in `team.njk`. Add or remove entries freely; the grid adapts.
- Photos: square, 400×400, under 60 KB, in `src/assets/images/team/`. Keep `alt=""`, because the name is printed beside each photo. Get each person's consent before publishing their photo.

## Files
- `team.css`
- `team.njk`

This section must not import files from any other section. Shared styles live in `src/css/`, shared behaviour in `src/js/` and `src/components/`.
